# Git Setup Commands for career-referee Repository

## Step 1: Initialize Git Repository
```bash
git init
git add .
git commit -m "Initial commit: Career Referee for Engineers - Kiro Week 6 Challenge"
```

## Step 2: Connect to GitHub Repository
```bash
git branch -M main
git remote add origin https://github.com/infrawithshobhit/career-referee.git
git push -u origin main
```

## Step 3: Verify Repository

- ✅ .kiro/ directory with steering files

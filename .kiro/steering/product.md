# Product Overview

Career Referee for Engineers is a data-driven career decision tool that provides objective guidance for engineering professionals through quantitative role matching.

## Core Purpose
Help engineers make informed career decisions by evaluating their fit for different engineering roles using mathematical analysis across 5 key dimensions:
- Coding Skill
- Ops Experience  
- Stress Tolerance
- Salary Ambition
- Work-Life Balance

## Target Roles
- SRE (Site Reliability Engineer)
- DevOps Engineer
- Platform Engineer
- Cloud Engineer

## Key Features
- 5-question assessment with 1-5 rating scale
- Euclidean distance algorithm for role matching
- Match percentages and detailed analysis
- Trade-off analysis (gains/losses)
- Growth path recommendations
- Risk profile assessment

## User Experience
Simple 3-step process: Assessment → Analysis → Results with personalized career recommendations and actionable insights.
